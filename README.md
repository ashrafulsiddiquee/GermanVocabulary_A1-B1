# KhanSoft German Vocabulary (A1 · A2 · B1)

A fast, interactive, and trilingual web platform designed to help learners master German vocabulary from beginner (A1) to independent fluency (B1).

👉 **Live Demo:** [https://ashrafulsiddiquee.github.io/GermanVocabulary_A1-B1/](https://ashrafulsiddiquee.github.io/GermanVocabulary_A1-B1/)

---

## 🌟 Overview

KhanSoft German Vocabulary provides a complete curriculum aligned with the official CEFR framework. It includes authentic textbook sentences, translations in English and Bengali (বাংলা), audio pronunciation, and interactive study engines.

* **Total Vocabulary:** 2,731 authentic words and phrases
* **Total Lessons:** 43 structured units
* **Languages Supported:** German (Deutsch), English, and Bengali (বাংলা)
* **Hosting:** 100% client-side on GitHub Pages

---

## 🚀 Key Features

* **3D Active Recall Flashcards:**
  * Flip cards with a single click or spacebar.
  * Shows German words, grammatical gender, English meaning, and Bengali translation.
  * Displays authentic example sentences with full translations.

* **Dual Testing Modes:**
  * **Standard Quiz:** Practice with randomized 10-question multiple-choice sessions.
  * **Audio-Quiz:** Listen to spoken German and select the correct translation to build listening skills.
  * Missed words are automatically saved to your **Hardest Words** list.

* **Grammar & Case Laboratory:**
  * Color-coded noun genders: Blue for Masculine (*der*), Red for Feminine (*die*), and Green for Neuter (*das*).
  * Shows case changes across Nominativ, Akkusativ, and Dativ for each noun.

* **43-Lesson Categorized Explorer:**
  * Filter words by CEFR level (A1, A2, or B1).
  * Filter by specific lesson topic or grammatical gender.
  * Real-time search in German, English, or Bengali.

* **Daily Study Habit Tracker:**
  * Built-in 15-minute daily study timer.
  * Daily study streak counter to keep you motivated.
  * Saves all progress, starred items, and quiz scores locally in your browser.

* **Theme Support:**
  * Smooth switch between Dark Mode and Light Mode.
  * Fully responsive design for mobile phones, iPads, tablets, and laptops.
